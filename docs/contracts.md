# Contracts & Guidelines

This document governs the use of AI tools and the fundamental design principles of the WeBelong platform.

## 1. Stitch Usage Contract (AI Design)

### Authority
Technology serves the "belonging-first" mission. Any AI-generated output (Stitch MCP) that conflicts with core contracts is invalid.

### Green List (Allowed)
- UI Scaffolding, visual hierarchy refinement, accessibility improvements.
- Neutral component composition (buttons, cards, inputs).
- Performance optimization (refactoring CSS/structure).

### Red List (Forbidden)
- **NO Onboarding Logic**: No generation of steps or state transitions.
- **NO Gamification**: No progress bars, badges, or "streaks".
- **NO Behavioral Nudges**: No high-pressure copy or guilt-tripping.
- **NO Inference**: No attempts to infer user identity or mood from data.

### Alignment Clause
The Belonging-First principle (Safety, Privacy, Neutrality) **ALWAYS** wins. AI output is a "hallucination of intent" if it violates these boundaries.
